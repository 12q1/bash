This repo holds my personal shell/dotfiles setups, one directory per environment.

## `profiles/`

Actively maintained configs. Currently just:

- **[`win_gitbash`](profiles/win_gitbash/)** — Git Bash on Windows: prompt, aliases, vim, and
  a handful of CLI tools (eza, zoxide, fzf, bat, delta, lazygit, yazi, btop, starship). This
  is the one I actually use day to day; see its own README for install steps and design notes.

More profiles (e.g. a Linux/WSL dev environment) may show up here over time as I rebuild them.

## `archive/`

Old setups from earlier machines/OSes that I no longer run or maintain, kept around because
they're fun to look back on. Nothing in here is expected to still work as-is — see
[`archive/README.md`](archive/README.md).

---

You are free to use any of this however you like, but be aware that running random scripts
from the internet is not advisable — always read a script before running it. I will sometimes
update or maintain the active profile(s) above but take no responsibility for damage. Get in
touch if you'd like to make suggestions or modify something.
